# SwathProfile4QGIS v2.1.0

从栅格数据（高程、坡度、起伏等要素）沿基线提取横截面剖面的 QGIS 插件。

A QGIS plugin for extracting swath profiles from raster layers (elevation, slope, roughness, etc.) along baselines.

---

## 功能 Features

### 1. 数据输入与兼容性 Input & Compatibility
- **基线输入** — 支持选择现有线图层作为基线，或在地图上直接绘制新基线。
- **多要素处理** — 支持仅对选中的线要素进行剖面提取。
- **自动投影转换** — 自动处理基线与栅格图层之间的坐标系转换，确保投影精确对齐。

### 2. 条幅采样与平滑 Swath Sampling & Smoothing
- **条幅区域采样** — 沿基线提取指定宽度的带状区域，逐点采集栅格数值（支持高程、坡度、起伏等任意要素）。
- **灵活参数设置** — 支持自定义条幅宽度、采样步长、平行剖面线数量。
- **参数属性绑定** — 支持使用矢量图层属性字段或表达式，为每条基线单独配置专属的采样参数。
- **一键曲线平滑** — 工具栏提供快捷平滑开关，并可通过下拉菜单快速调节四档平滑强度（低、中、高、超强），实时改善曲线视觉走势。
- **自适应宽度匹配** — 条幅范围与扫描线长度自动匹配每条线的实际设定宽度。

### 3. 统计分析 Statistics
- **统计曲线绘制** — 自动计算并绘制最大值 (Max)、最小值 (Min)、平均值 (Mean) 以及上下四分位数 (Q1, Q3) 剖面线。
- **定量指标计算** — 自动计算局部起伏度指数 (Relief)、地形起伏度指数 (HI) 以及横向积分指数 (THi / THi*)。

### 4. 交互式图表 Interactive Chart
- **实时扫描联动** — 鼠标在剖面图表中移动时，地图上自动、无延迟地同步显示对应的空间位置扫描线。
- **多维缩放平移** — 支持鼠标滚轮缩放、中键拖动平移、左键框选局部放大、右键拖动单独缩放 X/Y 轴，以及双击重置视图。
- **动态十字准星** — 带有实时数值标注的十字参考线，方便精准读取任意位置的坐标。
- **自适应纵坐标** — 纵坐标轴名称默认自适应匹配所选栅格图层名称。
- **一键自定义轴名** — 点击工具栏专属按钮，即可一键输入或清除自定义的纵坐标名称。
- **全面中文支持** — 深度优化字体渲染，支持中文坐标轴标题与负号的完美呈现，无任何乱码或显示异常。

### 5. 地图条幅显示 Swath Band
- **可视化条幅范围** — 在地图上直观显示平角矩形条幅范围，支持自定义填充色、边界色及透明度。
- **范围矢量导出** — 支持将条幅范围一键保存为标准矢量地理文件（SHP、GeoJSON、GPKG），且导出的图层或生成的临时内存图层会自动加载至 QGIS 图层面板。
- **地图画线样式** — 地图交互式画线工具采用醒目的红色实线样式，方便直观勾勒。
- **扫描线层次优化** — 优化地图上动态扫描线的图层层级（Z-Ordering），确保其始终清晰显示在条幅范围多边形上方。

### 6. 数据导出与原生提示 Export & Native Prompt
- **图表图片导出** — 支持将当前剖面图表一键导出为高清 PNG、PDF 或矢量 SVG 格式图片。
- **CAD 剖面导出** — 将 2D 剖面图表与 3D 空间线合并为单一的【导出 CAD】下拉按钮。支持直接保存为 DXF 或 DWG 格式（DWG 格式自动兼容处理），并可在导出时选择不同的 AutoCAD 兼容版本。
- **剖面数据导出** — 支持将详细的剖面采样与统计数据导出为 CSV/TXT 格式，导出的数据与当前的曲线平滑状态保持完全一致。
- **原生消息条提示** — 所有导出成功后，均会在 QGIS 地图画布上方滑出原生的、非阻塞的绿色消息提示栏，展示完整导出路径，并提供一键【在文件夹中显示】功能（直接在系统资源管理器中打开并定位选中导出的成果文件）。

## 安装 Installation

1. 将插件文件夹复制到 QGIS 插件目录下（如 `profiles/default/python/plugins/`）。
2. 在 QGIS 主菜单中打开「插件」->「管理并安装插件」，找到并启用 **SwathProfile4QGIS**。

## 使用 Usage

1. 点击 QGIS 工具栏上的插件图标打开参数配置面板。
2. 选择待分析的栅格数据（投影坐标系）和基线线图层。
3. 设置所需的采样参数后，点击「处理」。
4. 在下方弹出的剖面面板中交互式查看图表、调节平滑强度或自定义坐标轴。

## 运行环境 Environment

- QGIS 3.16+
- Python 依赖库：matplotlib, numpy
